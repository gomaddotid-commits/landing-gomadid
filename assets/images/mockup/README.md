# Folder Mockup GoMad

Letakkan **gambar mockup asli (screenshot produk)** di folder ini dengan nama yang sama
untuk menggantikan placeholder SVG otomatis. Cukup replace file dengan ekstensi `.png` / `.jpg`
dan pastikan nama file sama, contoh:

| Nama file | Digunakan di section |
|---|---|
| `hero-app.svg` | Hero utama (dashboard customer) |
| `travel-search.svg` | Fitur Cari Travel |
| `seat-select.svg` | Fitur pilih kursi |
| `rental-lepas-kunci.svg` | Rental Lepas Kunci |
| `driver-app.svg` | Aplikasi Driver |
| `agency-dashboard.svg` | Dashboard Agency |
| `warung-pos.svg` | Warung / POS |
| `eticket.svg` | E-Ticket |

> Gunakan PNG/JPG dengan rasio yang sesuai (1200×760 untuk desktop, 480×960 untuk phone).
> Format SVG didukung langsung oleh browser.
